# Skryvo for Claude Code

Write posts in your brand's voice, schedule them to your connected social accounts, and read how they
performed, from Claude Code. The plugin adds Skryvo's MCP server and a skill that walks Claude through
choosing the brand and channels, drafting, getting your go-ahead, and scheduling.

## Install

```
/plugin marketplace add Skryvo/claude-plugin
/plugin install skryvo@skryvo
```

The first Skryvo tool call opens Skryvo's sign-in and consent page. You need a Skryvo account
(https://app.skryvo.ai) and, to publish, accounts connected under Settings › Connected Accounts.

## What it can do

List brands and channels, write a post for up to four platforms, schedule and cancel posts, list what is
scheduled, and read results. Details: https://skryvo.ai/agents

## Privacy

Skryvo receives only the tool calls Claude makes, never the rest of your conversation. Full policy:
https://skryvo.ai/privacy. Disconnect at any time in Skryvo under Settings › API & agents.

Support: support@skryvo.ai
